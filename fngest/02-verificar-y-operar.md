# 02 — Verificar y operar FNGest

## Comprobación mínima

1. Identificá la tarea, el recurso y la operación autorizados.
2. Revisá qué herramientas FNGest están **realmente disponibles** en tu sesión y sus parámetros.
3. Elegí una herramienta de solo lectura pertinente. Pedí el dato mínimo necesario para la tarea.
4. Separá el resultado: herramienta disponible, servidor responde, recurso permitido, operación permitida e identidad de auditoría. Cada punto requiere evidencia propia.
5. Registrá solo fecha, tipo de lectura, resultado y límite observado. No copies respuestas completas ni datos de clientes a esta carpeta.

Una lectura exitosa no prueba permiso para editar. No crees una tarea, nota, cliente o comentario de prueba para verificar conectividad. Si la lectura esperada no está publicada, buscá una lectura equivalente solo dentro del alcance acordado; si no existe, informá el límite.

## Cuando te pidan una edición

La operación debe estar autorizada en el proyecto que usa FNGest. Leé primero el registro exacto y el contrato de la herramienta. Si existe una fase de preparación o vista previa, revisá qué se modificaría. Aplicá solo el cambio pedido y, si es posible, releé el mismo registro para comprobar persistencia. Una respuesta de guardado no demuestra por sí sola que el cambio aparezca en la vista prevista.

Para notas autorizadas, el equipo usa fecha **AAAA-MM-DD** en negrita, agente real y proyecto de origen. Confirmá que MCP soporte el formato requerido antes de afirmar que quedó aplicado.

## Si falla

| Caso | Qué hacer |
| --- | --- |
| No aparecen herramientas FNGest | Comprobá que el agente cargó la conexión aprobada y consultá a Gustavo. No infieras que el servidor no existe. |
| Pide autenticación | Coordiná la renovación con Gustavo por el mecanismo privado aprobado. |
| Responde, pero no aparece el recurso | Revisá alcance, filtros y permisos de tu usuario con el responsable. Un resultado vacío no prueba ausencia del recurso. |
| Falta la operación o el formato | Informá la limitación y acordá la parte afectada. No sustituyas una lectura por escritura. |
| Cambia la atribución de auditoría | Verificá por el mecanismo administrativo aprobado; no deduzcas identidad solo de una respuesta. |

**FNGest se opera exclusivamente por MCP.** La prueba de un integrante o del piloto no demuestra permisos de otro.
