# Meta Ads por MCP

La conexión documentada usa el servidor remoto oficial de Meta en `https://mcp.facebook.com/ads`. El usuario entra con Facebook; la autorización y las cuentas accesibles dependen de **ese usuario**, no del nombre del agente o modelo. No requiere crear una app de desarrollador ni pegar un token de Marketing API.

1. [Conectar en Codex o adaptar a otro agente](01-conectar.md).
2. [Comprobar cuenta, identidad y permisos](02-comprobar.md).
3. [Cambios, otra PC y problemas frecuentes](03-operar-y-migrar.md).

La disponibilidad de herramientas de edición no confirma que una persona pueda editar todas las cuentas. Verificá cada caso. [Fuente Meta](https://es-la.facebook.com/business/tools/ads-mcp-server).
